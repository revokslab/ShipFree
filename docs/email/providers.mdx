# Email providers

Configure the provider with `EMAIL_PROVIDER`. If set, ShipFree uses that provider. If not set, it auto-discovers the first configured provider.

## Resend

- `RESEND_API_KEY`
- `RESEND_DOMAIN`

## Postmark

- `POSTMARK_API_TOKEN`

## Plunk

- `PLUNK_API_KEY`

## MailKite

- `MAILKITE_API_KEY`

[MailKite](https://mailkite.dev) is inbound-first: it sends transactional mail *and* receives — parsed inbound email plus the SPF/DKIM verdict arrive as one signed webhook, so support inboxes, reply-to-thread and agent mailboxes need no second provider.

## Nodemailer (SMTP)

- `SMTP_HOST`
- `SMTP_PORT`
- `SMTP_USER`
- `SMTP_PASS`
- `SMTP_SECURE`

## Custom provider

Implement a custom provider and register it in `src/lib/messaging/email/providers/custom.ts`.

<Info>
  Set `DEFAULT_FROM_EMAIL` and `DEFAULT_FROM_NAME` to control sender identity.
</Info>
